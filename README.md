# PromtLab ✨

**PromtLab** — Android-приложение-генератор промтов для промт-инженера.
Нативный стек: **Kotlin + Jetpack Compose + Material 3**. Современный интерфейс,
**выдвижное меню слева**, тёмная и светлая темы, 6 акцентных палитр,
генерация промтов для **текста и изображений**, библиотека шаблонов,
избранное и обучающие материалы.

## Возможности

| Раздел меню | Что делает |
|---|---|
| **Создать промт** | Конструктор текстового промта: роль модели, задача, контекст, аудитория, тональность, формат, объём, язык, ограничения и 8 приёмов промт-инжиниринга (Chain-of-Thought, few-shot, самокритика, уточняющие вопросы и др.). Мгновенный предпросмотр, счётчик символов/слов/токенов и живая оценка качества с подсказками. Кнопка «вдохновение» подставляет готовую идею. |
| **Изображения** | Режим «Изображение» **внутри того же генератора** (сегмент вверху экрана): сюжет, детали, 12 стилей, освещение, кадр/оптика, палитра, настроение, соотношение сторон, выбор нейросети (Midjourney v6, SDXL, DALL·E 3, Flux.1), negative prompt и автоматические параметры. Prompt / Negative / Параметры собираются раздельными блоками, есть 7 готовых идей. |
| **Шаблоны** | 16 проверенных промтов по категориям (тексты, маркетинг, код, бизнес, дизайн, обучение, аналитика, ролевые) с поиском и фильтрами. Один тап — и пресет открыт в конструкторе. |
| **Избранное** | Сохранённые промты в Room: по умолчанию избранные, переключатель открывает всю коллекцию; поиск по названию/тексту/категории, просмотр и редактирование, копирование, шаринг, удаление. |
| **Обучающие материалы** | 8 коротких уроков по промт-инжинирингу: анатомия промта, роль, контекст, формат, Chain-of-Thought, few-shot, промты для изображений, частые ошибки. Примеры можно скопировать, прогресс чтения сохраняется и виден в меню. |
| **Настройки** | Системная/светлая/тёмная тема, динамические цвета Android 12+, акцентные палитры, счётчик токенов, экспорт всех промтов, очистка коллекции. |
| **О программе** | Версия, возможности, стек, ссылки на репозиторий и шаринг приложения, лицензия MIT. |

Навигация — **выдвижное меню слева** (ModalNavigationDrawer): пункты с иконками и
описаниями, счётчики сохранённых/избранных промтов, прогресс обучения и быстрый
переключатель темы. Дополнительно: edge-to-edge, анимации переходов,
snackbar-уведомления, адаптивная иконка запуска, автосохранение настроек в DataStore,
юнит-тесты генераторов.

## Готовый APK

Собранный debug-APK лежит прямо в репозитории: [`artifacts/promtlab-debug.apk`](artifacts/promtlab-debug.apk)
(~18 МБ, подписан debug-ключом, SHA-256 в [`artifacts/promtlab-debug.apk.sha256`](artifacts/promtlab-debug.apk.sha256)).

```bash
# установка по USB
adb install -r artifacts/promtlab-debug.apk

# или скопируйте файл на телефон и откройте — разрешите установку из этого источника
```

APK пересобирается автоматически в CI (`Android CI`) и коммитится в ветку ботом,
поэтому это всегда сборка из последнего коммита. Debug-ключ годится только для
тестирования: для Google Play нужен release-keystore (`./gradlew :app:assembleRelease`).

## Как собрать

Требования: **JDK 17+**, **Android SDK 35** (Android Studio Koala/Ladybug или новее).

```bash
# вариант 1 — Android Studio
# File → Open → папка проекта → Sync Project with Gradle Files → Run ▶

# вариант 2 — командная строка
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk

# юнит-тесты генераторов
./gradlew :app:testDebugUnitTest
```

Сборка также выполняется в CI: workflow `.github/workflows/android.yml` прогоняет
тесты и собирает debug APK, артефакт `promtlab-debug-apk` доступен на странице
запуска GitHub Actions.

Если Gradle wrapper не запускается (например, на машине нет прав на `gradlew`),
выполните один раз `gradle wrapper --gradle-version 8.10.2` или соберите проект
через Android Studio — она сама подхватит Gradle 8.10.2 из
`gradle/wrapper/gradle-wrapper.properties`.

## Архитектура

```
app/src/main/java/com/promtlab/app/
├── MainActivity.kt              # точка входа, edge-to-edge, тема
├── Graph.kt                     # лёгкий сервис-локатор (Room + DataStore)
├── data/
│   ├── model/PromptModels.kt    # доменные модели текстового промта, enum'ы
│   ├── model/ImageModels.kt     # модели изображения: стиль, свет, кадр, палитра…
│   ├── PromptGenerator.kt       # сборка текстового промта, оценка, токены
│   ├── ImagePromptGenerator.kt  # prompt / negative / параметры, оценка, идеи
│   ├── TemplateLibrary.kt       # 16 готовых шаблонов
│   ├── LearningLibrary.kt       # 8 уроков по промт-инжинирингу
│   ├── local/                   # Room: entity, DAO, database
│   ├── repository/              # PromptRepository
│   └── settings/                # DataStore: тема, акцент, флаги, прогресс уроков
├── ui/
│   ├── AppViewModel.kt          # единое состояние: генератор, история, настройки
│   ├── GeneratorMode.kt         # режим конструктора: текст / изображение
│   ├── navigation/              # NavHost, Destinations, выдвижное меню AppDrawer
│   ├── components/              # дизайн-система: карточки, поля, чипы, кнопки
│   ├── screens/                 # generate / templates / favorites / learn / about
│   │   └── generate/            # GenerateScreen + ImagePromptPane (режим картинок)
│   ├── settings/                # экран настроек
│   └── theme/                   # ColorScheme, палитры, типографика
└── util/                        # буфер обмена, шаринг, ссылки, форматирование
```

**Паттерн:** однонаправленный поток данных — `StateFlow` в `AppViewModel` →
Compose-состояние через `collectAsStateWithLifecycle()`; события (сохранение,
удаление, тосты) идут через `SharedFlow`. Состояние конструктора и режим
«текст/изображение» живут на уровне Activity, поэтому не теряются при переходе
между разделами меню.

**Стек:** Kotlin 2.0.21 · Compose BOM 2024.12.01 · Material 3 · Navigation Compose ·
Room 2.7 (KSP) · DataStore Preferences · Coroutines/Flow · AGP 8.7.3.

## Как устроены генераторы

### Текстовый промт

`PromptGenerator.build(form)` — детерминированная сборка структурированного промта:

```
# РОЛЬ      → «Ты — {role}. Тон общения: {tone}.»
# ЗАДАЧА    → задача пользователя
# КОНТЕКСТ  → продукт, данные, ограничения
# АУДИТОРИЯ → уровень и ожидания читателя
# ОГРАНИЧЕНИЯ → что нельзя делать
# ФОРМАТ ОТВЕТА → Markdown / JSON / таблица / шаги…, объём, язык
# КАК РАБОТАТЬ → выбранные приёмы (CoT, few-shot, самокритика…)
# КРИТЕРИИ КАЧЕСТВА → конкретность, отсутствие выдумок, соблюдение формата
```

### Промт для изображения

`ImagePromptGenerator.build(form)` собирает три независимых блока:

```
# PROMPT (EN)        → subject, details, стиль, свет, оптика, палитра, настроение, качество
# NEGATIVE PROMPT    → артефакты, текст, водяные знаки (+ предупреждение для Midjourney/DALL·E)
# ПАРАМЕТРЫ          → Midjourney: --v 6.1 --style raw --q 2 --ar 16:9
#                       SDXL: Steps / CFG / Sampler · Flux: guidance / steps · DALL·E: hd
# КАК ИСПОЛЬЗОВАТЬ   → куда вставлять блоки и как уточнять результат
```

Оценка качества — прозрачная эвристика по заполненности блоков (10–100 %),
токены считаются как `длина / 3.2`. Всё локально: приложение не отправляет
промты в сеть.
